# Web App

The web application for Dead Simple Task List, built with React, TypeScript, and Vite.

## Getting Started

This is a minimal React + TypeScript + Vite setup with HMR and ESLint configured.

## Development

Install dependencies and start the development server:

```bash
npm install
npm run dev
```

## Building

Build for production:

```bash
npm run build
```

## ESLint Configuration

For production applications, enable type-aware lint rules by updating `eslint.config.js` with `tseslint.configs.recommendedTypeChecked` or stricter variants.

Optionally add React-specific rules using `eslint-plugin-react-x` and `eslint-plugin-react-dom`.
