Dead Simple Task List - Basic GraphQL + Railway Plan

1) Keep frontend where it is:
- Existing app: apps/web (React + Vite)

2) Add a backend app:
- New folder: apps/api
- Language/runtime: TypeScript + Node.js
- Add GraphQL server (Apollo Server or GraphQL Yoga)

3) Add database on Railway:
- Create Railway project
- Add PostgreSQL plugin
- Copy DATABASE_URL env var into api service

4) Define first GraphQL schema:
- Query: taskListByToken(token)
- Mutations: createTask, updateTask, moveTask, deleteTask
- Connect resolvers to Postgres

5) Deploy two services on Railway:
- web service root: apps/web
- api service root: apps/api

6) Configure environment variables:
- API service: DATABASE_URL, PORT
- Web service: VITE_GRAPHQL_URL=https://<api-domain>/graphql

7) Connect frontend to GraphQL:
- Install Apollo Client (or urql/graphql-request)
- Replace local/mock task operations with GraphQL queries/mutations

8) Verify end-to-end:
- Open web app
- Create/edit/move tasks
- Confirm data persists after refresh

9) Nice-to-have next:
- Add auth or board passcodes
- Add migrations
- Add logging and error handling
